Play with Markdown

April, 28 2013. 3 minutes read.



I was enjoying writing an old school way to create websites. Yes. Writing it using plain HTML. Beside train your gut's, it also give you freedom to design the so called layout.
The question is, is there any approach to yet another way writing a publication? The answer is yes, yes and yes. Here came the Markdown. Instead of Markup language in HTML, this Markdown was gain the popularity as the alternative.

How come?

Because, markdown really cut the crap syntax. My first impression is how to write the heading 3. Just use ###. Learn the markdown here, here and here.

Well. Try the editor bellow. Move your mouse over on bottom-right side. It will show eyes icon (for preview) and square with arrow inside (for full screen mode). For knowing side by side markdown, use the full screen mode. You will know the awesomeness of markdown and Bob is your uncle.
